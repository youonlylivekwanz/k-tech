# Kwane — High-Performance & Editorial Portfolio

An intentional, anti-slop developer & creative engineer portfolio built with React 19, Framer Motion v12, and Vite.

## Architecture

- **Stack**: React 19, Vite 6, Framer Motion 12
- **Styling**: Native CSS Variables, Glassmorphism, Zero-bloat utility architecture
- **Design Tokens**: Obsidian Black (`#080709`), Surface Elevation (`#111014`), Champagne Gold (`#e2d9cc`), Sky Accent (`#38bdf8`)
- **Typography**: Italiana & Cormorant Garamond (Editorial / Accents), Space Grotesk (Tech Metadata & Monospaced Specs), Plus Jakarta Sans (Body)
- **Performance**: Strict 60fps frame budget, sub-16ms touch latency target

## Featured Case Studies

1. **Ni** — High-fashion editorial & liquid motion experience (React 19, Framer Motion 12, Canvas Particle Shader, Bento Grid).
2. **Semadi Properties** — Commercial property platform & executive analytics dashboard.
3. **Cookies-Tho** — Lightweight interactive consumer brand experience with pure semantic HTML5, CSS3, and vanilla JS.

## Getting Started

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
